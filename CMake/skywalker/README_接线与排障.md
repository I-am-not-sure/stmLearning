# STM32F103 + Skywalker 30A V2 + T60-EDU 接线与排障

## 先确认这套硬件能否搭配

- `T60-EDU` 是三相无刷电机，三根 U/V/W 线本身不接收 PWM；PWM 是发给外置电调的。
- 当前外置电调是 `Skywalker 30A V2`，所以控制协议必须遵循电调说明书：50 Hz，最低油门约 1100 μs，最高油门约 1940 μs。
- `电机.md` 中的 1500 μs 停止、1100/1900 μs 正反转，是配套双向驱动器的接口定义，不能直接套用到 Skywalker 的白色油门线上。
- Skywalker 30A V2 的动力输入只允许 3-4S LiPo。不要接同学 Mamba 工程使用的 22.5 V/6S 电源，也不要直接接 24 V；这会触发输入电压异常报警，并存在损坏电调的风险。
- T60-EDU 资料给出的工作范围是 11.1-25.2 V，因此可先用 3S，或最多按 Skywalker 规格使用 4S，但达不到 24 V 额定点的最大推力。若需要 24 V 满功率，应更换支持 6S 且与所需正反转方式匹配的电调。

## 接线

全部断电并拆除危险负载后接线。T60 水下推进器测试时必须完全浸没、牢固固定，导流罩内不得有人手或异物。

| STM32F103C8T6 | Skywalker 30A V2 | 说明 |
|---|---|---|
| `PA6 / TIM3_CH1` | 白线 `Signal` | 50 Hz 油门 PWM |
| 任一 `GND` | 控制插头黑线 `GND` | 必须共地 |
| 不接 | 控制插头红线 `5V BEC` | 首次测试悬空绝缘，开发板用 USB 独立供电 |

不需要 K1、K2 或其他控制输入。程序只使用 `PA6` 输出信号；`PA7` 仅作为可选的运行状态 LED，不接也不影响电调。

动力回路：

```text
3S（或合规的 4S）电池正极  -> ESC 粗红线
3S（或合规的 4S）电池负极  -> ESC 粗黑线
ESC 三根相线                -> T60 的 U/V/W 三根线（相序任意）
```

方向不对时，完全断电后交换任意两根电机相线。当前程序只测试一个方向。

## 正常启动测试

1. 让推进器完全浸没并固定，确保人员和异物远离导流罩；先断开电调动力电。
2. 给 STM32 开发板上电或按复位。PA6 立即开始发送 1100 μs。
3. 在 8 秒等待窗口内给电调接通合规的 3S/4S 动力电。
4. 正常应听到上电音、锂电节数提示音，最后一声长鸣表示电调已就绪。
5. 从 STM32 复位时刻算起，第 8 秒程序自动切到 1200 μs，低速运行 2 秒。
6. 第 10 秒程序自动回到 1100 μs，此后永久保持停止，直到再次复位开发板。
7. 若异常抖动、持续报警、发热或无法停止，立即断开动力电。

串口 `PA2/PA3` 为 115200、8-N-1。也可以在调试器中观察 `app_live.motor_command`：前 8 秒为 1100，随后 2 秒为 1200，此后为 1100。

## 油门行程校准

当前无按键测试固件不执行油门行程校准。Skywalker V2 出厂范围本来就是 1100-1940 μs，正常情况下可直接识别本程序的 1100 μs 最低油门。

油门校准要求在电调确认最高点后，由操作者在 5 秒内将信号切到最低点。这必须增加一个按键、串口命令或其他可靠输入，不能用固定延时安全地猜测人工接电和鸣叫时刻。若待机波形已确认是 1100 μs 仍提示油门不在最低点，再临时增加控制输入进行校准，不要反复尝试自动最高油门程序。

## 持续鸣叫的定位顺序

1. 先用万用表测量 ESC 粗红/粗黑线之间的实际电压。30A V2 必须在 3-4S 范围内。
2. 示波器或逻辑分析仪测 `PA6` 对 `ESC 黑线/GND`：周期应约 20 ms；前 8 秒高电平约 1.10 ms；随后 2 秒约 1.20 ms；然后恢复 1.10 ms。
3. 确认测量参考地确实接在 ESC 黑线，而不是只接了 PA6 一根线。
4. 确认白线接 PA6；红色 BEC 线没有误接 GPIO/3.3V。
5. 再根据鸣叫节奏判断：

| 重复鸣叫特征 | Skywalker V2 官方含义 | 优先检查 |
|---|---|---|
| 成对鸣叫反复出现 | 输入电压超出范围 | 是否误用 22.5/24 V，电池是否过放或接触不良 |
| 单个较长鸣叫反复出现 | 没收到油门信号 | PA6、白线、共地、PWM 是否启动 |
| 很急促的单短鸣反复出现 | 油门不在最低点 | 测量待机脉宽是否确实为 1100 μs |
| 校准后仍反复短鸣 | 校准行程过窄 | 临时增加可靠输入，再按官方 1940/1100 μs 流程校准 |

如果听到的是完整的上电旋律反复重播，而不是某一种固定报警节奏，说明电调可能在反复掉电重启。此时检查电源限流是否过小、接头或焊点是否接触不良，并在报警过程中测量 ESC 输入端电压是否明显跌落。

鸣叫的长短和间隔非常关键；若仍不能判断，录一段包含完整循环的音频，并同时提供电池实测电压和 PA6 波形。
