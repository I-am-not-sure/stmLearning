# 调试操作规程

## 1. 准备工作

- 控制器：具备PWM输出功能的设备(如Arduino、树莓派、STM32开发板)。
- 被控设备：舵机或推进器(含电调ESC)。
- 连接线材：标准杜邦线或动力电源线。

## 2. 调试步骤

|  | 动作说明 | 关键要点 |
| --- | --- | --- |
| 硬件连接 | 1.信号线连接控制器PWM引脚   2.电源正极连接供电正极   3.电源负极连接GND | 必须确保控制器与被控设备共地 |
| 系统上电/使能 | 先输入1500μs信号，再开启电源 | 推进器将发出上电提示音/舵机会回到中位 |
| 动态调试 | 逐渐改变信号数值 | 观察并确认推进器/舵机旋转方向及响应 |

# 使用接线说明

## 推进器接线指南

分为：

### 内置电调

即推进器内部已经包含电调，主要涉及：

* 电源供电线
* PWM/控制信号线
* GND/地线

### 外置电调

即电机需要连接单独的 ESC/电调，再由电调连接：

* 电源
* PWM 控制信号
* 电机三相线
