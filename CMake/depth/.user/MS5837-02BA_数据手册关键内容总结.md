# MS5837-02BA 深度传感器数据手册总结

> 源文件: ENG_DS_MS5837-02BA01_A8 (TE Connectivity, REV A8 12/2019)

---

## 1. 基本规格

| 参数 | 数值 |
|---|---|
| 压力范围 | 300 ~ 1200 mbar |
| 温度范围 | -20 ~ +85 °C |
| 供电电压 | 1.5 ~ 3.6 V（典型 3.0V） |
| 分辨率 (OSR=8192) | 压力 0.016 mbar, 温度 0.002 °C |
| 相对精度 | 压力 ±0.5 mbar (600~1000mbar, 20°C) |
| 待机电流 | 0.01 µA (25°C) |
| 转换电流 (OSR=8192) | 20.09 µA |
| 峰值电流 | 1.25 mA (转换期间) |
| 封装尺寸 | 3.3 × 3.3 × 2.75 mm |

## 2. 引脚定义

| Pin | 名称 | 功能 |
|---|---|---|
| 1 | GND | 电源地 |
| 2 | VDD | 正电源 (1.5~3.6V) |
| 3 | SCL | I2C 时钟线 |
| 4 | SDA | I2C 数据线 |

> **注意：** VDD 与 GND 之间需要 **100nF 去耦电容**，尽量靠近传感器放置。

## 3. I2C 通信

- **7 位地址:** `0x76`
- **写地址 (8 位):** `0xEC` (= 0x76 << 1)
- **读地址 (8 位):** `0xED`
- **最大时钟:** 400 kHz
- **HAL 库:** 配置为 `I2C_ADDRESSINGMODE_7BIT` 时传入 `0xEC`

### 3.1 命令一览表

| 命令 | 十六进制 | 说明 |
|---|---|---|
| Reset | `0x1E` | 复位传感器，上电后必须发送一次 |
| Convert D1 (OSR=256) | `0x40` | 压力转换 (最短) |
| Convert D1 (OSR=512) | `0x42` | 压力转换 |
| Convert D1 (OSR=1024) | `0x44` | 压力转换 |
| Convert D1 (OSR=2048) | `0x46` | 压力转换 |
| Convert D1 (OSR=4096) | `0x48` | 压力转换 (当前代码使用) |
| **Convert D1 (OSR=8192)** | **`0x4A`** | **压力转换 (最高精度，16.44ms)** |
| Convert D2 (OSR=256) | `0x50` | 温度转换 (最短) |
| Convert D2 (OSR=512) | `0x52` | 温度转换 |
| Convert D2 (OSR=1024) | `0x54` | 温度转换 |
| Convert D2 (OSR=2048) | `0x56` | 温度转换 |
| Convert D2 (OSR=4096) | `0x58` | 温度转换 (当前代码使用) |
| **Convert D2 (OSR=8192)** | **`0x5A`** | **温度转换 (最高精度，16.44ms)** |
| ADC Read | `0x00` | 读取 24 位转换结果 |
| PROM Read | `0xA0` ~ `0xAE` | 读取校准系数 (地址 A0,A2,A4,A6,A8,AA,AC) |

> **发现：** 示例代码注释写的是 OSR=8192，但实际用的命令 `0x48`/`0x58` 是 OSR=4096。真正 OSR=8192 的命令是 `0x4A`/`0x5A`。当前 OSR=4096 也能工作，延迟时间 20ms 足够覆盖转换时间。

### 3.2 转换时间 (必须等待的时间)

| OSR | 典型值 | 最大值 (编程时应使用) |
|---|---|---|
| 256 | 0.54 ms | 0.56 ms |
| 512 | 1.06 ms | 1.10 ms |
| 1024 | 2.08 ms | 2.17 ms |
| 2048 | 4.13 ms | 4.32 ms |
| 4096 | 8.22 ms | 8.61 ms |
| **8192** | **16.44 ms** | **17.2 ms** |

### 3.3 通信流程

**复位:**
```
START → 写地址 0xEC → 发 0x1E → STOP → 等 20ms
```

**读 PROM (示例: 读地址 0xA2 即 C1):**
```
START → 写地址 0xEC → 发 0xA2 → STOP
START → 读地址 0xED → 收 2 字节 (MSB→LSB) → STOP
```

**压力/温度转换 + 读取:**
```
START → 写地址 0xEC → 发转换命令 → STOP → 等转换完成
START → 写地址 0xEC → 发 0x00 → STOP
START → 读地址 0xED → 收 3 字节 (23→16, 15→8, 7→0) → STOP
```

## 4. PROM 校准系数

每个传感器出厂时在两个温度、两个压力下标定，生成 6 个 16 位系数存入 PROM (共 112 位)。

| 地址 | 系数 | 含义 | 类型 |
|---|---|---|---|
| 0xA0 | C0 | CRC + 版本号 / 产品类型 | unsigned int 16 |
| 0xA2 | C1 | 压力灵敏度 (SENS|T1) | unsigned int 16 |
| 0xA4 | C2 | 压力偏置 (OFF|T1) | unsigned int 16 |
| 0xA6 | C3 | 压力灵敏度的温度系数 (TCS) | unsigned int 16 |
| 0xA8 | C4 | 压力偏置的温度系数 (TCO) | unsigned int 16 |
| 0xAA | C5 | 参考温度 (T|REF) | unsigned int 16 |
| 0xAC | C6 | 温度的温度系数 (TEMPSENS) | unsigned int 16 |

### 典型值 (数据手册示例，仅参考)

| 系数 | 典型值 |
|---|---|
| C1 | 46372 |
| C2 | 43981 |
| C3 | 29059 |
| C4 | 27842 |
| C5 | 31553 |
| C6 | 28165 |

> 这些值是出厂标定的，**每个传感器都不同**，不可复制使用。

## 5. 补偿计算公式 (核心算法)

### 5.1 变量定义

| 变量 | 含义 | 类型 | 范围 |
|---|---|---|---|
| D1 | 原始压力值 (24 位) | uint32 | 0 ~ 16777216 |
| D2 | 原始温度值 (24 位) | uint32 | 0 ~ 16777216 |
| dT | 实际温度与参考温度差值 | int32 | -16776960 ~ 16777216 |
| TEMP | 实际温度 (×100, 即 2000 = 20.00°C) | int32 | -4000 ~ +8500 |
| OFF | 实际温度下的压力偏置 | int64 | 约 5.7×10^9 |
| SENS | 实际温度下的压力灵敏度 | int64 | 约 3.0×10^9 |
| P | 温度补偿后的压力 (×100, 即 110002 = 1100.02 mbar) | int32 | 1000 ~ 120000 |

### 5.2 一阶补偿 (First Order)

```
dT   = D2 - C5 × 256
       = D2 - C5 × 2^8

TEMP = 2000 + dT × C6 / 8388608
       = 2000 + dT × C6 / 2^23

OFF  = C2 × 131072 + (C4 × dT) / 64
       = C2 × 2^17    + (C4 × dT) / 2^6

SENS = C1 × 65536  + (C3 × dT) / 128
       = C1 × 2^16    + (C3 × dT) / 2^7

P    = (D1 × SENS / 2097152 - OFF) / 32768
       = (D1 × SENS / 2^21    - OFF) / 2^15

P_mbar = P / 100     ← 转为 mbar 单位
```

### 5.3 二阶温度补偿 (Second Order)

**低温修正 (TEMP < 20°C 即 < 2000 时生效):**

```
Ti    = 11 × dT² / 34359738368
       = 11 × dT² / 2^35

OFFi  = 31 × (TEMP - 2000)² / 8
       = 31 × (TEMP - 2000)² / 2^3

SENSi = 63 × (TEMP - 2000)² / 32
       = 63 × (TEMP - 2000)² / 2^5
```

**高温修正 (TEMP ≥ 45°C 即 ≥ 4500 时，02BA 一般水深场景很少用到):**
```
T2    = 2 × dT² / 137438953472
OFF2  = 1 × (TEMP - 2000)² / 16
SENS2 = 0
```

**应用补偿:**
```
OFF2  = OFF  - OFFi
SENS2 = SENS - SENSi
TEMP2 = TEMP - Ti

T_°C    = TEMP2 / 100          ← 温度 (°C)
P_mbar  = (D1 × SENS2 / 2^21 - OFF2) / 2^15 / 100  ← 压力 (mbar)
```

## 6. 压力转深度

```
Depth(cm) = 0.983615 × (P_current - P_atmosphere)
```

- `P_current` = 当前压力 (mbar)
- `P_atmosphere` = 水面大气压 (mbar)，开机时采集
- 系数 `0.983615` ≈ 淡水下 1 mbar ≈ 0.98 cm 水柱

| 标准大气压参考值 | mbar |
|---|---|
| 海平面标准大气压 | 1013 |
| 代码中 fallback 值 | 101300 (注意：P 是 ×100 的，所以 101300 = 1013 mbar) |

## 7. CRC 校验 (可选)

PROM 地址 0xA0 的高 4 位存储 CRC-4 校验码。可以用以下 C 代码验证 PROM 数据完整性：

```c
unsigned char crc4(unsigned int n_prom[]) // n_prom[8], n_prom[7] 须为 0
{
    int cnt;
    unsigned int n_rem = 0;
    unsigned char n_bit;
    
    n_prom[0] = ((n_prom[0]) & 0x0FFF);  // CRC 位清零
    n_prom[7] = 0;
    
    for (cnt = 0; cnt < 16; cnt++) {
        if (cnt % 2 == 1)
            n_rem ^= (unsigned short)((n_prom[cnt>>1]) & 0x00FF);
        else
            n_rem ^= (unsigned short)(n_prom[cnt>>1] >> 8);
        
        for (n_bit = 8; n_bit > 0; n_bit--) {
            if (n_rem & 0x8000)
                n_rem = (n_rem << 1) ^ 0x3000;
            else
                n_rem = (n_rem << 1);
        }
    }
    
    n_rem = ((n_rem >> 12) & 0x000F);
    return (n_rem ^ 0x00);  // 返回值 == Cal_C[0]>>12 则校验通过
}
```

## 8. 调试注意事项

### 8.1 数据为零的原因排查
| 可能原因 | 检查方法 |
|---|---|
| I2C 接线错误 | 确认 SCL→PB6, SDA→PB7 |
| 传感器供电不足 | VDD=3.3V，检查 100nF 去耦电容 |
| printf/sprintf 不支持 %f | nano.specs 需加 `-u _printf_float` ✅ 已修复 |
| PROM 读取失败 | 复位后加足 20ms 延迟 |
| ADC 结果恒为 0 | 转换命令后等待时间是否足够 |

### 8.2 上电时序
- VDD 上电必须从 0V 连续上升到工作电压，不可有台阶
- 如果上电失败，可以发送多个 SCL 脉冲 + Reset 恢复

### 8.3 防水
- 传感器自带凝胶填充 + O 型圈槽
- O 型圈规格: 内径 1.8±0.05mm, 线径 0.8±0.03mm
- 壳体孔径: 3.07±0.03mm
